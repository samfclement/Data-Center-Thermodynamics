# Data Center Thermodynamics

**An interactive visual simulation of thermal-energy transfer through a data center cooling system.**

[**Launch Interactive Simulator**](https://samfclement.github.io/Data-Center-Thermodynamics/)

## Overview

Data Center Thermodynamics is an educational simulation illustrating how thermal energy generated by server electronics is transported through a data center's cooling infrastructure and ultimately rejected into the atmosphere.

Follow a highlighted packet of thermal energy through the server hardware, air-handling systems, glycol cooling loop, refrigeration cycle, condenser-water loop, and cooling tower.

The simulation uses animated equipment illustrations and guided explanations to make complex thermodynamic processes easier to visualize.

## What You'll Learn

- How electrical energy becomes waste heat in server components.
- How heatsinks and server fans transfer thermal energy into moving air.
- How hot aisle containment directs warm return air toward air-handling units.
- How cooling coils transfer energy into a glycol/water mixture.
- How a refrigeration system uses evaporation, compression, condensation, and expansion to move thermal energy.
- How condenser water transports heat to a cooling tower.
- How evaporation and airflow reject thermal energy into the surrounding atmosphere.

## How to Use the Simulator

**Automatic Mode:** Watch the complete thermal-energy journey as the animation advances through each stage and repeats.

**Manual Mode:** Move through the individual stages at your own pace using the navigation controls.

**Equipment Inspection:** Select individual components to explore their function and internal heat-transfer mechanisms.

**Playback Controls:** Pause, resume, restart, replay stages, or adjust animation speed.

## Simulation Scope

This application is intended for conceptual engineering education.

The equipment illustrations and thermodynamic processes are simplified to prioritize visual understanding. The simulator does not perform numerical thermal analysis or computational fluid dynamics.

The illustrated airflow arrangement represents one specific data center cooling configuration and should not be interpreted as universal to all facilities.

## Run Offline

To use the simulator without an internet connection:

1. Download the `index.html` file from this repository.
2. Open the downloaded file in a modern web browser.
3. Interact with the simulation normally.

No installation, Python environment, or internet connection is required.

## Project Information

This public repository contains the standalone, deployable simulator. The development source code and build tooling are maintained separately.

The simulator is designed as a visual learning resource for students, technicians, and others interested in data center cooling and thermodynamics.
